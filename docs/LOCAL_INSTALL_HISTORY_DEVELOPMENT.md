# 이 PC의 작업 이력 — 개발 기능

2026-10-16. `app/`의 미출시 Development 기능이다. 공개 rc3·rc4에는 포함되지 않는다.

GUI의 **Local history on this PC · not device identification** 영역에서 마지막으로 완료한 작업을 확인할 수 있다. **Installed firmware · Last inspection**은 기기에 질의한 결과이고, 로컬 이력은 이 PC에서 수행한 작업 기록이다. 두 결과는 별도로 표시한다.

## 기록하는 작업

- **HHKB RT / HOLD / 순정 복원:** 기존 업데이터가 성공하고 일반 모드 재연결을 확인한 뒤 기록한다. 재연결 성공은 펌웨어 전체를 읽어 검증했다는 뜻은 아니다.
- **R3S RT:** 파일과 manifest 생성 완료만 기록한다. 공식 REALFORCE 앱에서 실제 설치했는지는 알 수 없다.
- 취소·실패한 작업은 성공 이력에 추가하지 않는다. 과거 실기 시험이나 다른 폴더에서 수행한 작업도 자동으로 소급 등록하지 않는다.

현재 화면에는 작업 종류, 대상 모델, 완료 시각(UTC), 앱 빌드와 파일 SHA-256 앞부분을 표시한다. 상세 기록은 **Open Output Folder**로 여는 폴더의 `install_history.json`에 저장된다. 새 개발 앱에서 성공한 작업이 없으면 이 파일이 없는 것이 정상이다.

저장 내용은 완료 시각, 작업 종류, 대상 모델, 사용한 파일의 전체 SHA-256, 앱 빌드·채널, 의도한 RT 설정 또는 HOLD 슬롯 설정, 재연결 결과다. 앱 빌드는 키보드에 설치된 펌웨어 버전이 아니다. HOLD의 대상 모델은 지원 빌더의 PD-KB800W이며, 이 이력을 현재 연결된 개체와 대조하지 않는다.

## 해석과 보관

이력은 **현재 연결된 키보드의 식별 증거가 아니다.** 모델이 같은 다른 키보드, 다른 PC·공식 앱에서의 업데이트, 수동 변경을 구별할 수 없다. 설정도 펌웨어에서 읽어 온 값이 아니다. 현재 펌웨어 계열은 **Inspect firmware** 결과와 그 한계를 확인해야 한다. 로컬 이력으로 Unknown을 정확한 버전으로 바꾸지 않는다.

최근 20개 작업을 저장하며 USB 경로·일련번호·원시 응답·펌웨어 파일 자체는 넣지 않는다. 자동 업로드하지 않는다. 파일을 삭제하면 로컬 이력이 초기화되며 키보드는 바뀌지 않는다. 이 파일은 사용자가 수정할 수 있는 보조 기록으로, 서명된 검증 자료가 아니다.

이력 저장 실패가 이미 성공한 설치를 실패로 바꾸거나 자동 재플래시를 유발하지 않는다. 앱 여러 개를 동시에 사용하면 마지막 기록이 서로 덮어써질 수 있으므로 완전한 감사 로그로 사용하지 않는다.

## 개발 검증

앱 전체 테스트 **94개 통과**. 이력 모듈 14개와 GUI 연동 9개를 포함한다. 성공·실패·취소, 실제 사용 바이트의 해시, HOLD 설정 보관, R3S 파일 생성과 설치 구별, 저장 오류 후 성공 유지, 숨겨진 실제 Tk 화면의 식별/이력 분리를 확인했다. 장치 접근과 펌웨어 쓰기는 모의 처리했다. 새 실기 검증 결과는 아니다.

추가 USB 문자열로 기기 자체의 식별 정보를 읽는 기능은 별도 연구 단계이며, 이 이력 기능이 해당 펌웨어 통합을 대신하지 않는다.
