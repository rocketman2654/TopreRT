# Project introduction

## English

TopreRT is an unofficial Windows toolkit for bringing Rapid Trigger to supported REALFORCE R3S and HHKB keyboards. It validates your original firmware, creates a configured image and provides a live sensor Observer. R3S images are installed through official REALFORCE software; HHKB uses the updater built into TopreRT. HHKB HOLD/SpaceFn is available as an alternative firmware workflow.

This preview adds device diagnostics, conservative legacy firmware identification and identity checks across HHKB update reconnects. A stock A0.48 restore and RT R60/P90 reinstallation passed on one PD-KB800W, with user-confirmed typing and Observer behavior. Other models and profiles, the revised HOLD writer and interrupted-update recovery have separate validation limits. Original and modified firmware binaries are not included. TopreRT is not affiliated with the keyboard manufacturers.

## 한국어

TopreRT는 지원되는 REALFORCE R3S와 HHKB 키보드에 Rapid Trigger를 적용하기 위한 비공식 Windows 도구입니다. 사용자가 준비한 순정 펌웨어를 검증하고 설정에 맞는 파일을 생성하며, Observer로 센서 반응을 관찰할 수 있습니다. R3S는 생성한 파일을 공식 REALFORCE 프로그램에서 설치하고, HHKB는 TopreRT 내장 업데이터로 설치합니다. HHKB HOLD/SpaceFn은 별도의 대체 펌웨어로 선택할 수 있습니다.

이번 프리뷰는 기기 진단, 기존 펌웨어 계열 식별, HHKB 업데이트 재연결 시 기기 동일성 확인을 추가합니다. PD-KB800W 한 대에서 순정 A0.48 복원과 RT R60/P90 재설치, 실제 입력과 Observer 동작을 확인했습니다. 다른 모델·프로필, 새 HOLD 업데이터와 중단 복구는 별도 검증 범위입니다. 순정·수정 펌웨어 바이너리는 배포하지 않으며 제조사와 제휴한 제품이 아닙니다.
