# Project introduction

## English

TopreRT is an unofficial Windows toolkit for bringing Rapid Trigger to supported REALFORCE R3S and HHKB keyboards. It validates your original firmware, creates a configured image and provides a live sensor Observer. R3S images are installed through official REALFORCE software; HHKB uses the updater built into TopreRT. HHKB HOLD/SpaceFn is available as an alternative firmware workflow.

This unreleased Development build adds deterministic HHKB RT/HOLD build identification, versioned catalogs and recipe-based RT settings display alongside diagnostics and updater reconnect checks. GUI-generated Golden RT R32/P32 and one-slot SpaceFn 250 ms passed installation, reconnect, identification and user functional checks on one PD-KB800W. Other models/configurations and interrupted-update recovery require separate validation. SpaceFn can delay spaces during overlapping typing; this behavior limitation is unchanged. Original and modified firmware binaries are not included. TopreRT is not affiliated with the keyboard manufacturers.

## 한국어

TopreRT는 지원되는 REALFORCE R3S와 HHKB 키보드에 Rapid Trigger를 적용하기 위한 비공식 Windows 도구입니다. 사용자가 준비한 순정 펌웨어를 검증하고 설정에 맞는 파일을 생성하며, Observer로 센서 반응을 관찰할 수 있습니다. R3S는 생성한 파일을 공식 REALFORCE 프로그램에서 설치하고, HHKB는 TopreRT 내장 업데이터로 설치합니다. HHKB HOLD/SpaceFn은 별도의 대체 펌웨어로 선택할 수 있습니다.

이번 미출시 개발판은 기기 진단과 업데이트 재연결 확인에 더해 HHKB RT/HOLD 빌드 식별, 버전별 카탈로그와 생성 기록에 따른 RT 설정 표시를 제공합니다. PD-KB800W 한 대에서 GUI 생성 Golden RT R32/P32와 SpaceFn 250ms 한 슬롯의 설치·재연결·식별·사용자 기능 확인을 마쳤습니다. 다른 모델·설정과 중단 복구는 별도 검증 대상입니다. 빠른 겹침 입력에서 SpaceFn 공백이 지연되는 동작은 현재 한계로 유지합니다. 순정·수정 펌웨어 바이너리는 배포하지 않으며 제조사와 제휴한 제품이 아닙니다.
