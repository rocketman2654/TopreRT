# TopreRT 사용 설명서

TopreRT는 지원되는 순정 펌웨어를 바탕으로 RT 또는 HHKB HOLD/SpaceFn 펌웨어를 만들고 동작을 관찰하는 비공식 Windows 도구입니다. 제조사 공식 제품이 아닙니다. 순정 파일과 수정된 펌웨어 파일은 배포본에 포함하지 않습니다.

## 설치와 준비

1. 배포 ZIP 전체를 쓰기 가능한 폴더에 압축 해제합니다.
2. Python 3.12를 Python Launcher와 Tkinter를 포함해 설치합니다.
3. 앱 폴더의 `Setup_Demo.bat`를 한 번 실행합니다. USB 라이브러리는 앱 전용 환경에 설치됩니다.
4. `Start_TopreRT_GUI.bat`로 실행하고 USB로 키보드를 연결합니다.
5. Keyboard에서 기종을 선택합니다. Browse에는 **제조사의 지원되는 순정 원본**을 선택합니다. 현재 장치에서 펌웨어를 읽어오는 기능은 아니며, 이전 TopreRT 출력 파일을 순정 입력으로 선택하면 안 됩니다.

R3S는 모델별 A0.12 `.rfb`, HHKB PD-KB800W는 정확한 A0.48 `.hfb`가 필요합니다. 같은 버전 이름이어도 파일이 다르면 거부될 수 있습니다. 검증을 우회하지 말고 [R3S 지원표](../backends/r3s/SUPPORTED_FIRMWARE.md)를 확인하세요.

## R3S: 파일 생성 후 공식 프로그램에서 설치

1. Release / Re-press 또는 프리셋을 선택합니다.
2. **Create Firmware File**을 누릅니다. 이 단계는 파일만 만듭니다.
3. **Open Output Folder**를 눌러 방금 생성된 `.rfb`를 찾습니다.
4. 공식 REALFORCE 소프트웨어에서 해당 파일을 선택하여 업데이트합니다. 순정 원본이나 `.manifest.json`을 선택하지 않습니다.
5. 정상 입력과 Observer 동작을 확인합니다.

공식 프로그램의 최신/동일 버전 제한과 오류 화면은 버전에 따라 확인이 필요합니다. 파일이 거부되면 오류 문구·공식 앱 버전·기종을 기록하세요. 이 안내는 임의의 버전 강제 설치 방법을 제공하지 않습니다.

## HHKB RT: 앱 안에서 생성과 설치

1. **RAPID TRIGGER (RT-only)**를 선택하고 거리값을 정합니다.
2. Observer와 공식 HHKB 앱 등 다른 키보드 프로그램을 닫습니다.
3. **Create & Install RT**를 누르고 설정과 실제 업데이트 여부를 확인합니다.
4. 앱이 파일 생성과 내장 업데이터 설치를 수행합니다. 정상 재연결 완료까지 USB를 유지하고 PC가 절전 모드에 들어가지 않게 합니다.
5. HHKB로 입력한 뒤, 설치한 값과 같은 GUI 프로필로 Observer를 확인합니다. Inspect firmware로 RT 계열을 확인할 수도 있습니다.

별도 업데이터 실행 파일을 찾거나 생성된 `.hfb`를 공식 앱에서 다시 설치할 필요는 없습니다. 이번 새 업데이터의 순정→RT 복원 실기 결과는 PD-KB800W 한 대에 대한 것입니다. [검증 범위](HARDWARE_RESULT_20261015.md)를 참고하세요.

## HHKB HOLD / SpaceFn: 생성과 설치를 두 단계로 진행

1. **SPACEFN / GENERIC HOLD**를 선택합니다. SpaceFn은 Load SpaceFn preset을 사용할 수 있습니다.
2. Source(대상 키), Tap(짧게 눌렀을 때), Hold(길게 눌렀을 때), 시간 기준을 설정합니다.
3. **1. Create HOLD File**로 파일을 만들고 검증합니다. 아직 장치에 적용되지 않았습니다.
4. 다른 키보드 프로그램을 닫고 **2. Install HOLD**를 누릅니다. 표시된 확인 문구를 입력하면 실제 설치가 시작됩니다.
5. 정상 재연결 뒤 설정한 짧은 누름/긴 누름 동작을 확인합니다.

RT-only와 HOLD/SpaceFn은 대체 빌드입니다. 선택 버튼은 다음에 설치할 기능을 고르며, 클릭만으로 장치 모드가 바뀌지 않습니다. 이번 변경의 HOLD 업데이터는 모의 검사만 통과했으며 새 실기 설치 검증은 남아 있습니다. 기존 HOLD 코어의 시험 이력과 구별하세요.

## 파일과 상태 표시 이해하기

- `output`은 현재 실행 중인 앱 폴더 아래에 있습니다. 여러 복사본이 있으면 Open Output Folder로 현재 폴더를 여세요.
- 설정 변경과 **Check Settings**는 키보드를 변경하지 않습니다. 새 값을 적용하려면 기종별 설치 절차를 다시 거쳐야 합니다.
- Release/Re-press는 RT 해제·재입력을 위한 이동 거리이며, 최초 입력 지점을 독립적으로 설정하는 기능이 아닙니다. mm는 추정 환산값입니다.
- **Observer**의 기대값은 GUI 설정을 사용합니다. 설치된 거리 설정을 자동 조회하지 않으므로 설치한 프로필과 동일하게 맞추세요.
- **Detect**는 연결 검색, **Device diagnostics**는 HHKB 기기 정보 조회, **Inspect firmware**는 HHKB 펌웨어 계열 확인입니다. R3S의 설치 펌웨어 식별은 지원하지 않습니다.
- `Legacy TopreRT`와 정확한 버전 `Unknown`은 함께 나타날 수 있습니다. 기존 응답에 정확한 릴리즈 번호가 없다는 뜻이며 설치 실패를 의미하지 않습니다. A3도 TopreRT 버전 번호가 아닙니다. 반대로 응답 없음만으로 순정이라고 확정하지 않습니다.
- **Validate Stock File**은 입력 파일 검사, **Software Self-test**는 소프트웨어 검사입니다. 현재 키보드의 모든 기능이 검증됐다는 뜻은 아닙니다.
- **Restore Stock**은 HHKB에 순정 펌웨어를 실제로 써서 RT/HOLD를 제거합니다. 설정 초기화나 모든 고장 상태의 복구 기능이 아닙니다. R3S의 **Recovery Instructions**는 안내창입니다.

## 문제가 생겼을 때

USB 라이브러리 오류가 나면 앱을 종료하고 같은 폴더의 Setup_Demo.bat를 실행하세요. 업데이트가 중단되면 자동 재시도하거나 임의로 명령을 보내지 말고 오류 문구와 마지막 단계를 기록하세요. 연결이 돌아왔다는 메시지 뒤에도 직접 입력과 설치한 기능을 확인해야 합니다. Metadata v1 및 독립 Initial Press 조절은 이번 사용 절차에 포함되지 않는 연구 항목입니다.
